# S6：每轮刷新参考特征库——本轮执行计划

1. 从S5相同共同起点新增一个真标签纠错分支；第1轮使用原参考，第2—100轮每轮开始刷新全部源／目标参考。
2. 固定接收集合、真类身份、每目标5个源ID、目标图、边权、0.05系数、两套优化器起点、学习率及训练随机流。
3. 运行100轮×60步，仅评价固定第100轮；沿用200步源分类头校准，与封存S5纠错组比较。
4. 报告分类、逐类召回、四项几何、损失和参考变化，单列99次刷新的实际开销；不追加候选。

**状态：唯一新增分支已完成100轮训练、固定末轮评价及独立复核；本轮实验结束，不追加训练或候选。**

本轮使用 `ieee-experiment`。研究仍处于第三阶段；采用目标训练真标签作机制诊断，历史留出池用于开发验证，不称新无监督方法性能或新独立测试。HHAR继续排除，全部历史数据保留。

## 实际主要结果

**每轮刷新使第4类出现部分识别恢复，ACC与weighted F1提高，但主要的“第4类错分为第0类”仍保留，第三阶段验收未完成。** 恢复主要来自此前错分为第3类的那部分第4类样本；这比只看总ACC更准确地界定了刷新策略的作用范围。

等量留出池中，冻结组ACC=79.3734%、weighted F1=71.9930%；刷新组ACC=82.1554%、weighted F1=78.3394%。配对差值分别为+2.7820 pp、+6.3464 pp。刷新组第4类留出召回=15.0376%，目标训练召回=14.0780%。

按既定ACC及weighted F1均严格大于93%、四项几何同时通过的规则，本任务该分支验收：**未通过**。本轮没有重新评价类数或NMI，也不据单任务结果宣布整个第三阶段完成。

## 单因素与固定条件

科学问题是：共同起点的旧参考是否限制已经纠正的类别身份转化为正确分类。基线为S5真标签纠错分支：源监督、目标内部关系及双向跨域拉近共同训练，但参考向量始终冻结。S5证据显示第4类训练池和留出池识别均未恢复，因此将参考滞后列为本轮待检验原因。本轮属于机制诊断和实现策略验证，暂不作学术创新声明。

任务为BEARING源域20_0→目标域30_2，随机种子0，五个共有类别依次为0 ball、1 comb、2 health、3 inner、4 outer。

新增分支只更新参考向量值：两个域全部16320个训练样本同步导出两个弱视图，均值后单位化，停止梯度。每次采用与S5公共库相同的弱视图随机种子0及导出epoch参数100，因此同一样本的输入扰动固定；导出独立保存／恢复随机状态，模型及BN状态不变。目标图与跨域路由引用同一轮的相应向量，既定连接不重建、不改派。

11423个接收样本、纠正后的身份、57115个边槽及原权重保持不变；两组都包含2749个已纠正身份的真实第4类样本。共同模型／分类头及Adam状态从原v3末轮恢复，S5规定的编码器学习率1e-5→1e-7、头学习率0.003、batch64、100×60更新、固定末轮均沿用。第1轮损失完全一致，后续逐轮批次、增强、边槽、权重流及学习率由独立审计核对。

评价仍使用同一个自然4080例池及其固定等量3990例子集，每类798例；两者不是独立重复。训练与测试窗口ID互斥，原始记录／时间支持的独立性未证明。完整目标标签只在新模型预测封存后用于评分；S5封存指标直接复用。

## 结果解释与最必要的后续核验

**已获得的证据：刷新参考向量在本次固定条件下带来了部分分类恢复；仅解决参考滞后不足以达到第三阶段要求。** 等量池正确数从3167变为3278，净增111例：第4类增加120例，其他四类合计减少9例（第1类少1例，第3类少8例）。自然池ACC也从78.6029%变为81.4706%，方向一致，但自然池与等量池重叠，不是一次独立复现。

**剩余错误集中在第4类与第0类的表示及类别对应。** 目标第4类训练原型与正确源类4的余弦由0.266390变为0.289323，与错误源类0的余弦仍为0.943956，正确减最大错误的差仍为−0.654633。源训练ACC=99.9939%，源几何通过，但目标第4类大部分训练样本和留出样本仍错分。当前现象不能主要解释为留出集泛化差：训练池同样存在大面积错配。它也不是仅靠末端200步源头校准就能解决：未校准头的等量ACC=82.4812%、weighted F1=78.8793%、第4类132/798，仍呈相同瓶颈；按预定协议主要结果继续使用校准头，不临时更换读出。

**损失改善与真实类结构尚不等价。** 刷新组总损失首10轮0.05895146→末10轮0.04885797（下降17.12%），跨域两半项和0.16848825→0.08186844（下降51.41%）；目标查询半项也下降44.65%，不再只是源查询一侧改变。不过跨域损失在41—50轮均值0.05892217后回升至末10轮0.08186844，并非单调下降。目标几何训练损失下降42.86%，锁后真实类几何却仍不合格：R、ρ及g有所改善，B从0.988079变为0.989185，略增。训练使用推断关系，低关系损失不能替代真实类别紧凑和分离的验证。 若统一以源类中心作为参照，等量目标池R反而从84.7634°增至89.6902°，g从−79.8414°变为−89.8277°；因此目标自身中心参照下的部分改善，也不能解释为源、目标已经整体对齐。

**本轮隔离的是“全部参考向量是否每轮更新”。** 目标内部关系与跨域拉近都读取这些参考，所以不能进一步把收益唯一归于某一个跨域方向或某一种损失。刷新确实改变了优化轨迹，但没有测量各损失的梯度抵消，不能把“目标内部错误连接正在抵消纠错”写成已证实根因；跨域系数、固定关系与端点、共享参数及源监督之间的作用仍有待区分。单位特征满足相似度误差上界，但该上界本身不保证分类提升，相关文献也不能替代当前实验：[Cross-Batch Memory，CVPR 2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Wang_Cross-Batch_Memory_for_Embedding_Learning_CVPR_2020_paper.html)。

**93%数量门槛不能沿用“其他类始终3167例正确”的假设。** 按本轮其他四类实际3158例正确计算，第4类至少需要553/798（69.2982%），才使总正确数达到3711/3990=93.0075%。当前120例距离该条件还有433例；这仍只是ACC条件，不替代weighted F1和四项几何门槛。

最必要的下一步建议是做一次**不更新参数的分项梯度诊断**：固定已接收、真类为4且仍预测为0的训练样本，分别测量目标内部关系项、目标几何项、跨域目标查询项、跨域源查询项和源监督项对“靠近正确源类4、远离错误源类0”这一方向的贡献及相互夹角，并与已恢复样本比较。它可以区分“纠正方向太弱”和“不同训练目标相互抵消”两种解释，再决定唯一需要改动的损失；本轮未执行该后续诊断，也没有自动增加训练实验。

以上判断仅适用于BEARING 20_0→30_2、单种子、固定已接收真标签及既定100轮预算。保留原始数据划分、历史评价池和所有门槛；不称无监督方法已达到该表现，不将这一次受控机制结果推广到其他任务。更新数相同但刷新增加前向计算；本轮未设置等总计算量的额外训练对照。
