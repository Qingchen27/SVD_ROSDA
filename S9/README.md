# S9：表征、类别语义与几何的统一重构

## 本轮执行计划

固定七个数据集、八个迁移任务。每任务三个随机种子分别训练共享起点：30 轮源／目标无标签表征学习，再进行 100 轮源监督训练。种子 0 从同一源训练末态比较四组，种子 1、2 只重复预先指定的 FULL；每条适应轨迹 150 轮，每轮 60 步。共 24 个共享起点、48 条适应轨迹、619200 次优化器更新，完成全部训练后才统一评分。

| 组别 | 训练机制 | 本轮职责 |
| --- | --- | --- |
| SOURCE | 继续源监督分类 | 检验新表征与源学习的基础迁移能力 |
| SEMANTIC | 源分类＋每轮刷新的教师软类别监督＋目标表征一致性 | 检验类别语义学习的组合机制 |
| FULL | SEMANTIC＋同类别紧凑与不同类别中心正交 | 预先指定主方法，检查几何约束的增量作用 |
| ORACLE | 全部目标训练样本使用真实身份，保留一致性与几何训练 | 表征／优化能力诊断；不属于无监督域适应成绩 |

统一使用连续 128 维单位特征完成分类、几何评价和两种谱计数。源／目标使用相同的源训练通道归一化统计；分类交叉熵正常更新编码器及分类头。保留多尺度时序结构及分段池化；本轮不使用旧 FFT 分支、旧监督权重或末端分类头校准。这是完整方案重构，相对历史 S8 同时改变架构、预训练、损失与预算；只有本轮预设组间差异用于对应机制比较。

分类验收为 ACC 与 weighted F1 均严格大于 93%；几何门槛为 R≤20°、ρ≤0.10、B≤0.20、g>0。类数与 NMI 单独评价，当前计数对象为全部目标类别，尚不是开集未知类子集。

表征预训练的两个增强视图使用不变性、标准差下限与协方差正则，权重为 25/25/1；源类别交叉熵权重按源频率的 −0.5 次方归一化。语义分配的列先验来自源域自然频率，采用软约束，不使用目标真实类别比例，也不强制每个目标类等量。

无标签预训练采用[VICReg](https://arxiv.org/abs/2105.04906)的方差／一致性／协方差思路；全池匹配受[松弛最优传输](https://proceedings.mlr.press/v119/pham20a.html)及[UniOT](https://proceedings.neurips.cc/paper_files/paper/2022/hash/bda6843dbbca0b09b8769122e0928fad-Abstract-Conference.html)启发。这些是已有机制来源，当前组合仍需本轮对照验证，不宣称直接复现UniOT或已经构成新贡献。

匹配代价为 $C_{ic}=0.25(1-u_i^\top p_c)+0.5(1-a_{ic})$，其中u为单位化h、p为源类别原型、a为教师分类概率。优化 $\langle P,C\rangle+\epsilon\sum P(\log P-1)+\tau\mathrm{KL}(P^\top\mathbf1\Vert b_s)$，约束 $P\mathbf1=\mathbf1/N$；列缩放指数为 $\tau/(\tau+\epsilon)$。每轮只读当前教师全池表示，不固定历史边。

FULL把源样本与已接收目标样本按申请类别合并，源权重1、目标权重为匹配置信度。紧凑项为各类加权平均的“1−样本与本类单位中心余弦”，再对类别等权；正交项为不同类中心余弦的平方均值。ORACLE的目标权重均为1、身份为训练真标签。它同时增加标签正确性和覆盖，是系统可行性诊断，不能当作仅纠正身份的单因素实验。

## 解释边界与下一步

本轮全部模型先锁定，再读取目标真值评分；训练主线仅接收目标 x/id。ORACLE 是单独标记的诊断组，使用全部目标训练标签，其目标训练池及训练内开发池均为样本内评价；这两池不能作为 ORACLE 泛化证据。自然比例与等量留出池与训练样本 ID 不交叠，但历史开发曾观察这些池，原始记录／被试级独立性并未由 ID 不交叠保证，既有重叠窗口也未在本轮重划分。因此使用“历史留出池开发验证”表述。WISDM6 等量留出池仅 12 个样本，ACC 的单样本分辨率为 8.33 个百分点。

本轮不根据中途成绩更改池、种子、阈值、检查点或扩大搜索。完整结果首先回答：SOURCE 的基础迁移是否改善；SEMANTIC 的身份正确率与覆盖是否足够；FULL 的几何约束是否在保持分类的同时改善真实类别结构；ORACLE 在留出池能否形成可分、紧凑的表征。只有完成八任务共同证据核查后，才能确定下一项训练修改。
